# 主看板发布检查

发布范围为市场概览、城市分析、中指数据、统计局月报和房贷计算。入口、资源和数据由 `build_pages.py` 输出到 `dist/pages/`；本地小区研究目录不进入发布包。

## 数据检查

| 数据 | 发布要求 |
| --- | --- |
| 统计局月报 | 每期完整覆盖 70 城的新房、二手住宅及面积分档，共 560 行；原始页面与字段投影一致。 |
| 二手住宅价格 | 观测核对城市、月份、价格和原始文件哈希；缺失月按官方二手住宅环比链推导，无可信输入保持空值。 |
| 分类型挂牌报价 | 城市均价卡仅接受标题明确的住宅类型、年份、卡片月份和元/㎡单位；已知短域名分别核对城市，逐项匹配原始HTML和图表价格。原始字节哈希及证据随输入快照保存，Windows与Linux使用相同字节。 |
| 中指样本 | 城市、类型、时期唯一；新房、二手住宅、租金和地价分别保存单位与来源。 |
| 收入与工资 | 官方原文与投影一致；2014年全国中位数取年度经济运行报告的明确发布值，城乡指标保留年度公报来源，分别保存补充证据；最低工资不补推断档位。 |
| LPR | 自 2019-08 起保留逐月双期限报价，单位为百分比；完整月序列及官方来源证据通过核验。 |
| 历史保留 | 价格、来源时期与有效记录覆盖不得缩减；缺月、来源冲突和历史改写阻止发布。 |
| 前端映射 | 按城市、类别、月份及面积分档匹配；指数先减去 100 展示涨跌幅，不转换成元/㎡。 |

数据数量和最新月份以验证程序的实际输出为准。不同来源的最新时期可以不同；单个城市的最晚观测月不能作为全城覆盖月份。

## 图表与输入字段

| 展示 | 发布 JSON 字段与匹配规则 |
| --- | --- |
| 城市均价、总价、环比 | `cities[].monthly`，按城市与月份匹配；90㎡总价由单价折算，缺月断开。 |
| 上涨、持平、下跌城市数 | 相邻两月均有有效价格才可比；不可比城市独立计数。 |
| 能级价格指数 | 各能级使用全展示期间价格齐全的固定城市样本，2021-04=100；悬浮说明展示样本数量。 |
| 峰值回撤分布 | `cities[].drop_from_peak`，缺失值不进入分桶。 |
| 各城最高点 | `max_price`、`peak_date`、`peak_year` 必须对应本城有效月度序列的最大值；并列时标注最早月份。回撤用本城当前价格计算，历史月份只取截至该月的最高点。 |
| 全国及城市官方涨跌幅 | `housing_segments`，新房、二手住宅及环比、同比分别映射，不混用安居客挂牌时期。 |
| 收入与最低工资倍数 | `cities[].monthly` + `information.income`；收入不晚于价格年份，工资采用当月已公布的对应区域档位。全国参考采用各月有效城市均值，样本覆盖可随月份变化。 |
| 中指房价、租金排名 | `information.cih.prices`，各类型分别选择实际最新时期；新房/二手比必须同城同月。 |
| 土地面积 | `information.cih.land`，依据原文统计时期与万㎡单位；刷新月游标不能冒充统计时期。 |
| LPR | `information.macro.lpr.history`，逐月对应 1 年期和 5 年期以上绝对报价。 |
| 开发投资 / 新开工面积 | `information.macro.realestate.history`，默认使用 `items[].yoy` 的官方累计同比（%），保留增速正负号；累计总量模式使用 `items[].value`，不能当成单月走势。亿元、万㎡分别核对，住宅子项不能冒充总量。统计期与原始发布日期分别核验，1—2月合并，同比跳过无独立报告的1月并连接12月至次年1—2月，不插值、不生成1月数据。实际缺期用红色实线连接前后有效值，缺期值仍为空；逐段核对端点、颜色及线型，无两端值不外推，单独1月不标缺失。正常累计总量跨年重置不连接。时间由早到晚、纵轴由小到大，年份筛选后的摘要与最后一期图表数据一致。 |
| 统计局月报卡片 | `information.releases`，报告月、城市、住宅类型和面积档位同时匹配。 |
| 房贷本金与利息 | 由表单金额、示例利率、期限和还款方式计算；示例利率可修改，独立于 LPR 图，不宣称自动等于 LPR。 |

`chart_pipeline_audit.py` 从实际浏览器读取 ECharts 横纵轴与每个数据点，使用发布 JSON 独立重算预期值；任何未覆盖的新图表都会使验证失败。开发投资和新开工另从各期已保存的官方原文正文提取总量及“增长/下降”方向，独立于爬虫的表格解析核对发布值与同比正负号；浏览器检查默认同比、坐标方向、累计模式和历史年份摘要，证据逐期写入浏览器报告。房贷使用独立的闭式余额公式核对年度合计。桌面和 390px 手机同时检查筛选、历史月份、零利率、组合贷不同期限与月报未发布状态。

## 自动更新与失败处理

GitHub Actions 每天北京时间 18:00（UTC 10:00）执行，支持手动触发。工作流安装固定范围的 Python 依赖和 Chromium，恢复已发布输入快照，运行回归与干净目录重建，再进行隔离采集、验证和静态构建。

统计局每次到期都重新检查发布目录，不以月初检查替代本月后续检查。报告期从文章标题和正文核验，不能由执行日期减一个月直接写入。`update_status.json` 分别保存检查时间、实际数据时期、目录发布时期和等待发布状态：尚未发布继续保留上一报告；已经发布但抓取失败则保留旧表并在下一次到期检查重试。跨年与北京时间月份边界纳入回归。

单来源失败保留该来源有效历史。采集全部失败、超时或发布校验失败时，保留已发布价格、输入与证据，记录失败状态；安居客轮转游标单独保存，后续 runner 从该进度继续。文件发布清单去重，状态最后写入，发布中途失败恢复已触及文件。

最低工资每次刷新最新报告，并在单轮请求预算内补收已发现但漏存的历史报告；目录没有发布的季度不制造记录。失败或部分成功的来源至迟在下一次每日运行重试，正常周更来源继续按原周期检查。最低工资浏览器恢复仍保留原HTTP失败日志及恢复标记；收入、工资在发布前逐表重新解析证据核对时期、区域、数值和单位。

历史工资通过 `income_crawler.py --wage-archive` 恢复：月工资、小时工资分表必须同一期且完整覆盖31省区市和深圳，四档与五档均保留，未设置的档位仍为空。2015年6月的Excel附件从两张工作表读取原始单元格，不执行公式或采用公式缓存；图片表只使用逐格核对且绑定原图哈希的转录，未知或变更图片阻止发布。原文只提供年份或月份时，分别保存年、月精度，前端到年末、月末才采用该快照，不能在年初套用年末标准。

2026-10-09回填14期历史，合计28期工资快照，最早为2014年年末。2016年汇总表中宁夏第二档小时工资11.5元与自治区原始通知冲突，按[宁政发〔2015〕97号](https://www.nx.gov.cn/zwgk/qzfwj/201801/t20180115_668505.html)校正为13元，标准实施日期校正为2015-11-01，保留汇总表原值与校正证据。2015年9月表含尚未生效的10月、11月标准，整表隔离，不覆盖2015年6月的有效快照；审计原文保存在输入包中。2014—2025年全国、城镇、农村共36项年度中位数已核实齐全，不将全国口径当成各城市居民中位数。

房地产两图的普通线始终采用青色与蓝色；只有真实缺期的有效端点间显示红色直线及缺报图例。真实数据预览使用完整发布历史，模拟缺报图仅用于回归验证。

日志保存到 `output/update_logs/`，工作流上传日志供排查。来源网站改版、验证挑战及 GitHub 调度延迟需通过状态面板和 Actions 日志判断。

## 验证命令

```powershell
python -m unittest discover -s data_processing -p 'test_*.py'
python data_processing/verify_frontend_data.py --dashboard-only
python data_processing/verify_release_checkout.py
python data_processing/build_pages.py
python data_processing/verify_dashboard_browser.py
python data_processing/verify_income_browser.py
python data_processing/verify_city_peaks.py --directory dist/pages --browser
```

干净目录检查从仓库文件及 `published_inputs.zip` 恢复输入，离线重建后比对价格、中指、收入、工资与 LPR 历史，确认不依赖本机忽略文件。工作流另运行前端字段映射回归、JavaScript 语法检查和实际浏览器图表核对，报告与截图保存在 `output/release-browser/` 并上传 Actions 日志。修改手机布局时再执行 `verify_mobile_browser.py`。

收入专项浏览器检查从发布目录的实际 DOM 与 ECharts 选项读取数值，使用 Python 独立计算核对全部年度收支表、收入卡片、28期工资原表、原文链接、历史月份自动匹配和70城市所属行政区。覆盖早于工资记录的空状态、2014年补充中位数、宁夏2016年校正、已取消的第五档以及跨年对照；桌面和手机均执行，另核对320、768、1280、1920像素的历史查询布局与键盘操作。报告写入 `output/income-consumer-browser/report.json`，并纳入每日更新工作流。

## Cloudflare Pages 配置

| 配置项 | 值 |
| --- | --- |
| 项目根目录 | 仓库根目录，留空 |
| 构建命令 | `python data_processing/build_pages.py` |
| 输出目录 | `dist/pages` |
| 更新来源 | Actions 提交有效数据后，Git 集成触发重新部署 |

HTML 重新验证缓存，数据 JSON 缓存 5 分钟，静态资源缓存 1 天。构建检查静态文件范围、单文件大小和文件数量，依据 [Cloudflare Pages 限制](https://developers.cloudflare.com/pages/platform/limits/)；构建设置参照 [官方配置](https://developers.cloudflare.com/pages/configuration/build-configuration/)。

上线需提交发布脚本、工作流、依赖清单及已发布输入快照，并允许 Actions 写入仓库内容。首次手动执行工作流可检查远程网络和浏览器行为。当前尚未部署；本地验证不代表远程 GitHub runner 或线上部署已成功。
