# Montserrat

Source: https://github.com/google/fonts/tree/main/ofl/montserrat

License: SIL Open Font License 1.1, see Montserrat-OFL.txt. Downloaded 2026-09-17. Variable upright weight 100–900. WOFF2 is a format conversion of the upstream TTF, with font names and license metadata retained. Geometric sans-serif alternative to Novecento Wide; Latin/numerals use Montserrat, Chinese uses the MiSans/system fallback.
